# مصدر الكانفاس

ملفات `.dc.html` دي هي لوح كانفاس التصميم كلها، بالجولات القديمة (R2 لـ R13) والنسخة النهائية.
`canvas.json` فيه ترتيب اللوح والصفحات.

الصور في اللوح مكتوبة كـ `/_blob/<id>`، و `img/blobmap.json` بيربط كل id بالصورة بتاعته في `img/`.

النسخة النهائية: R18-System, R13-Mobile, R14-Evolve, R15-Call, R16-*, R17-*, R19-Dark-*.
الكانفاس الحي: https://claude.ai/artifact/JerkLWXK8H4zkey1GCkPps
